# 🛠️ دليل تجهيز Supabase لإطلاق ZeroPlus

> آخر تحديث: **2026-10-02** — بعد تدقيق كامل للكود مقابل قاعدة البيانات وإصلاح مشاكل التخزين والمزامنة.

## 🔴 ما الذي كان معطّلاً؟ (نتيجة التدقيق)

| المشكلة | الأثر | الحالة |
|---|---|---|
| جدولا `user_tasks` و`user_focus_sessions` **غير موجودين** في سكربت التهيئة إطلاقاً | كل مزامنة للمهام وجلسات التركيز تفشل بخطأ `42P01 relation does not exist` ويُتجاهل الخطأ بصمت | ✅ أُضيفا في `schema.sql` نسخة v2 |
| `profiles` ينقصه 6 أعمدة يستعملها الكود (`password_hash`, `auth_provider`, `email`, `avatar_url`, `node_crowns`, `learning_track`) | **تسجيل حساب جديد يفشل** بخطأ `PGRST204 column not found` | ✅ أُضيفت كلها |
| صلاحيات دور `anon` ناقصة | `42501 permission denied for table` في كل عملية | ✅ منحت الصلاحيات لكل الجداول |
| سياسات RLS لدور `anon` فقط | مستخدمو Google (دور `authenticated`) بلا وصول نهائياً | ✅ سياسات للأدوار الثلاثة |
| تسجيل الدخول على جهاز جديد لا يحفظ `device_id` | بعد الدخول تصبح كل عمليات الرفع معطّلة (لا معرّف للجهاز) | ✅ أُصلح في `index.html` |
| حفظ الصورة الشخصية كـ Data URL خام | يملأ `localStorage` (حد 5MB) ويفشل الحفظ بصمت | ✅ تُصغَّر الصورة إلى 256px قبل الحفظ |
| أي تغيير أثناء انقطاع الإنترنت يضيع | الطلاب يفقدون المهام وXP | ✅ طابور مزامنة محلي يُرفع تلقائياً |
| فشل المزامنة يُتجاهل بصمت (`catch(e){}`) | مؤشر السحابة يبقى أزرق/رمادي بلا سبب واضح | ✅ مؤشر حالات + رسائل خطأ تشرح الحل |

**الخلاصة:** شغّل ملف واحد (`supabase/schema.sql`) + انشر `index.html` المحدّث ← المزامنة تعمل بالكامل.

## 🚀 خطوات التشغيل (٥ دقائق)

### الخطوة 1 — افتح SQL Editor
1. ادخل على [supabase.com](https://supabase.com) وسجّل دخول.
2. افتح مشروعك (ZeroPlus).
3. من القائمة الجانبية اليسرى اختر **SQL Editor** ثم اضغط **New query**.

### الخطوة 2 — شغّل سكربت التجهيز
1. افتح ملف [`supabase/schema.sql`](./schema.sql) وانسخه **كامل**.
2. الصقه في محرر SQL واضغط **Run** (أو `Ctrl+Enter`).
3. انتظر رسالة النجاح. السكربت آمن — تقدر تعيد تشغيله وقت ما تبي بدون ما يخرب شيء.

### الخطوة 3 — تحقق من النتيجة
اختر وحدة من هذي الطرق:

- **التحقق الأدق من داخل Supabase** — بنفس SQL Editor نفّذ:
  ```sql
  SELECT table_name FROM information_schema.tables
  WHERE table_schema = 'public' ORDER BY table_name;
  ```
  ✔ المتوقع 5 جداول: `profiles`, `user_focus_sessions`, `user_node_progress`, `user_tasks`, `user_word_mastery`

  ```sql
  SELECT count(*) FROM public.profiles;
  SELECT count(*) FROM public.user_tasks;
  SELECT count(*) FROM public.user_focus_sessions;
  ```
  ✔ المتوقع: أصفار بدون أي خطأ `permission denied`.

- **من التطبيق نفسه (الأفضل):**
  1. افتح الموقع بعد نشر التحديث (أو محلياً).
  2. سجّل اسمك في شاشة الترحيب.
  3. راقب النقطة الصغيرة أعلى الصفحة (مؤشر السحابة):
     - 🟢 أخضر = متصل والمزامنة تعمل ← **جاهز**
     - 🟡 كهرماني = توجد عمليات بانتظار الرفع (تزول خلال ثوانٍ)
     - 🔴 أحمر = فشل مزامنة ← افتح Console وشف الرسالة (غالباً السكربت لم يُنفَّذ كاملاً)
     - ⚪ رمادي = لا إنترنت
  4. تأكد من **Table Editor**: بعد تسجيل الاسم يظهر صف في `profiles`، وبعد إضافة مهمة أو إنهاء جلسة تركيز تظهر صفوف في `user_tasks` و`user_focus_sessions`.

- **من خارج التطبيق (REST API):** استبدل `YOUR_ANON_KEY` بالمفتاح العام:
  ```
  https://lfygprhvyudatgwikwfy.supabase.co/rest/v1/user_tasks?select=*&limit=1&apikey=YOUR_ANON_KEY
  ```
  ✔ الصحيح: `[]` — ✘ الخطأ: `{"code":"42501"}` أو `{"code":"42P01"}`

- **اختبارات الكود:** من جذر المشروع نفّذ `node tests/run-tests.mjs` — ١٥ اختباراً لمنطق المزامنة (بدون إنترنت وبدون مكتبات).

## 🔐 ملاحظات أمنية مهمة قبل الإطلاق

### 1) مفتاح anon معرّض بالكود — هذا طبيعي ✅
مفتاح `anon` مصمم أصلاً ليكون عاماً (يشتغل في المتصفح)، والحماية الحقيقية تجي من سياسات RLS.
السكربت المرفق فعّل RLS مع سياسات تسمح للمستخدم المجهول `anon` ولمستخدم Google `authenticated` —
وهذا مطلوب لأن التطبيق يعتمد على `device_id`.

**الوجه الآخر (يجب أن تعرفه):** لأن التطبيق بدون تسجيل دخول Supabase إلزامي، أي شخص يملك المفتاح
العام (وهو معروف لأي زائر) يقدر نظرياً يقرأ أو يعدّل صفوف أي جهاز — بما فيها `password_hash`.
هذا مقبول لنسخة طلابية بسيطة، لكن إن بغيت حماية أقوى بالمستقبل:
- أضف Supabase Auth إلزامي واربط كل صف بـ `user_id` مع سياسة `auth.uid() = user_id`.
- أو انقل التحقق من كلمة المرور إلى دالة `SECURITY DEFINER` (RPC) وامنع قراءة `password_hash` نهائياً.
- كلمات المرور مخزّنة حالياً كـ SHA-256 بملح ثابت — ليست حماية قوية، فلا تستعمل كلمة مرور مهمة.

### 2) ⚠️ ترحيل المفاتيح الجديدة (مهم — نهاية 2026)
Supabase أوقفت إصدار المفاتيح القديمة على المشاريع الجديدة وستُجهز المفاتيح القديمة نهاية 2026:

| النوع القديم | البديل الجديد | ملاحظة |
|---|---|---|
| `anon` (JWT طويل) | `sb_publishable_...` | يُستخدم في المتصفح، بديل مباشر |
| `service_role` (سرّي) | `sb_secret_...` | للأوامر الخلفية فقط — **لا تضعه أبداً بالكود** |

**المطلوب منك:** من **Settings ← API Keys** خذ مفتاح `sb_publishable_` واستبدله
مكان `SUPABASE_ANON_KEY` في `index.html` (سطر واحد). ما يحتاج أي تغيير ثاني — السياسات
المبنية على دور `anon` تظل شغالة مثل ما هي.

### 3) مفتاح Groq — ✅ أُزيل من الكود
قسم المساعد معطّل (قريباً) وأُزيل معه محرك الذكاء الاصطناعي بالكامل: مفتاح `gsk_...`، نداء
`api.groq.com`، ودالة Supabase Edge Function `academic-ai` — لا يوجد أي مفتاح API في `index.html` أو `sw.js`.

- [ ] **إجراء متبقٍ (٥ دقائق):** ادخل [console.groq.com](https://console.groq.com) ← API Keys
  واحذف المفتاح القديم المسرّب نهائياً (كان منشوراً في Git، وإزالته من الكود لا تُلغي إمكانية استخدامه).

## 🧰 نصائح تشغيلية لمرحلة الإطلاق

| الموضوع | التوصية |
|---|---|
| **إيقاف المشروع تلقائياً** | الخطة المجانية توقف المشروع بعد أسبوع من عدم الاستخدام — أول يوم بالإطلاق راقب أن المؤشر أخضر، وفعّل زيارة دورية أو رقِّ للخطة Pro لو توقعت استخدام كثيف |
| **النسخ الاحتياطي** | الخطة المجانية بدون نسخ احتياطي تلقائي — كل فترة صدّر الجداول من Table Editor (CSV) أو شغّل `pg_dump` |
| **مراقبة الاستخدام** | راقب Dashboard ← Reports (طلبات API + حجم القاعدة). كل مزامنة = عدة طلبات REST |
| **Logs** | لو اشتكى طالب من عدم حفظ بياناته: Dashboard ← Logs ← PostgREST وشف الأخطاء مباشرة |
| **حجم الصور** | الصور تُصغَّر تلقائياً إلى 256px قبل الحفظ، فلا تحتاج Storage Bucket حالياً. لو أردت صوراً أكبر لاحقاً استخدم Supabase Storage مع سياسات bucket خاصة |
| **الحدود (Rate limits)** | الخطة المجانية تكفي لمئات الطلاب على الاستخدام الطبيعي |
