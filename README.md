# ZeroPlus (Z+) | زيرو بلس 🎓🇮🇶

**المنصة الأكاديمية والوزارية الشاملة للطلاب في العراق.**

### ✨ المميزات الرئيسية:
- **بومودورو وغابة التركيز التخيلية 🌲:** مؤقت دراسة احترافي يزرع شجرة سحرية في غابتك الخاصة مع كل جلسة مكتملة.
- **إدارة المهام الدراسية 📚:** تنظيم المحاضرات والفصول الوزارية مع نظام نقاط الخبرة (`XP`).
- **مزامنة سحابية ☁️:** حفظ تقدم الطالب (الاسم، القسم، XP، جلسات التركيز، المهام) في Supabase مع العمل بدون إنترنت (Offline-first).
- **قريباً ⏳:** قسما **البناء اللغوي** و**المساعد الأكاديمي** معطّلان مؤقتاً ويعرضان بطاقة «قريباً» — ستُطلق وظائفهما لاحقاً.
- **تطبيق ويب تقدمي (PWA) 📱:** قابل للتثبيت على جميع الهواتف والأجهزة اللوحية واللابتوب ويعمل بدون انقطاع.

### البنية التقنية
- واجهة واحدة ثابتة (`index.html`) بدون خطوات بناء — تنشر مباشرة على Cloudflare Pages.
- قاعدة بيانات: **Supabase** (Postgres + RLS) بهوية مجهولة تعتمد `device_id`.
- مكتبات عبر CDN: Tailwind، Supabase JS، Canvas Confetti، FontAwesome، خط Cairo.
- لا يوجد أي ربط بذكاء اصطناعي أو مفاتيح API خارجية في الكود حالياً (أُزيلت مع تعطيل قسم المساعد).

### المزامنة السحابية — الجداول المطلوبة
| الجدول | المفتاح | ما يحفظه |
|---|---|---|
| `profiles` | `device_id` | الاسم، القسم، الصورة، XP، دقائق التركيز، بيانات الدخول |
| `user_tasks` | `device_id + id` | مهام الطالب ووسومها وأولوياتها |
| `user_focus_sessions` | `device_id + id` | جلسات التركيز المنجزة |
| `user_node_progress` | `device_id + node_id` | **غير مستخدم حالياً** — محفوظ في المخطط لإطلاق قسم البناء اللغوي |
| `user_word_mastery` | `device_id + term_key` | **غير مستخدم حالياً** — محفوظ في المخطط لإطلاق قسم البناء اللغوي |

> كل تعريفات الجداول والصلاحيات وسياسات RLS جاهزة في ملف واحد: [`supabase/schema.sql`](supabase/schema.sql) — آمن لإعادة التشغيل.

### كيف تعمل المزامنة (Offline-first)
1. أي تغيير (مهمة، جلسة تركيز، XP، صورة) يُحفظ فوراً محلياً في `localStorage`.
2. يُسجَّل التغيير في **طابور مزامنة** (`zp_sync_queue`) حتى لا يُفقد أبداً.
3. يُرفع الطابور تلقائياً إلى Supabase عند: تسجيل الدخول، عودة الإنترنت، رجوع التطبيق للمقدمة، وكل ١٥ ثانية عند وجود فشل.
4. عند الدمج مع السحابة: بيانات السحابة + المحلية تُدمج (لا تُطمس مهمة محلية غير مرفوعة)، والترتيب محفوظ.

**مؤشر السحابة** أعلى الصفحة: 🟢 مزامن | 🟡 عمليات بانتظار الرفع | 🔴 فشل مزامنة (افتح Console) | ⚪ غير متصل.

### الاختبارات
اختبارات تلقائية لمنطق المزامنة (بدون أي مكتبات خارجية — تكفي Node.js):
```bash
node tests/run-tests.mjs
```
تشغّل سكربت `index.html` داخل DOM وهمي مع Supabase وهمي، وتتحقق من: إنشاء الحساب، المزامنة أثناء انقطاع الإنترنت، الدمج بدون فقدان بيانات، عزل بيانات كل مستخدم، الحذف الآمن، ومعالجة أخطاء الصلاحيات.

### النشر
الموقع منشور على Cloudflare Pages (`_headers` خاصة بمنصة Cloudflare).
أي تعديل مستقبلي على `index.html` أو `sw.js` يتطلب رفع رقم الإصدار `?v=` + `CACHE_NAME` في `sw.js` حتى يصل التحديث للأجهزة المثبتة.
