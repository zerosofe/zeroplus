كيف أبدّل المظهر (فاتح / داكن / تلقائي)؟

هل تستمر جلسة التركيز لو خرجت من التطبيق؟

نعم — المؤقت يُسلَّم للخدمة الخلفية فيكمل العدّ ويطلق التنبيه حتى لو صغّرت التطبيق أو أقفلت الشاشة أو أغلقت الصفحة.

أثناء الجلسة يظهر لك شريط مصغّر في كل الشاشات بالوقت المتبقي مع زرّي إيقاف مؤقت/إنهاء، وإشعار مستمر في شريط إشعارات الهاتف يحمل نفس الأزرار.

تهيئة جدول الأشجار في Supabase

خطوة واحدة لمرة واحدة — يفعّل الحفظ السحابي الكامل للغابة

  1. افتح مشروعك في Supabase ← SQL Editor ← New query.
  2. الصق الكود بالأسفل ثم اضغط Run.
  3. ارجع للتطبيق واضغط «إعادة المحاولة» — ستُرفع الأشجار المحفوظة على جهازك تلقائياً.
-- ZeroPlus: جدول الأشجار (غابة الإنجاز)
create table if not exists public.trees (
    id          bigint not null,
    user_id     text   not null,
    tree_type   text   not null default 'oak',
    duration    integer not null default 25,
    planted_at  timestamptz not null default now(),
    created_at  timestamptz not null default now(),
    primary key (user_id, id)
);

alter table public.trees enable row level security;

drop policy if exists "zp_anon_all_trees" on public.trees;
create policy "zp_anon_all_trees" on public.trees
    for all to anon using (true) with check (true);

drop policy if exists "zp_auth_all_trees" on public.trees;
create policy "zp_auth_all_trees" on public.trees
    for all to authenticated using (true) with check (true);

grant select, insert, update, delete on table public.trees to anon, authenticated, service_role;

الأسئلة الشائعة

كيف أنزّل/أثبّت التطبيق؟

أندرويد (Chrome): اضغط زر ⋮ أعلى المتصفح ← «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية»، أو استخدم زر «تثبيت» أعلى الصفحة.

آيفون (Safari): اضغط زر المشاركة ← «إضافة إلى الشاشة الرئيسية» ← إضافة. (التثبيت من Safari فقط وليس من Chrome).

اللابتوب: أيقونة التثبيت داخل شريط العنوان يميناً، أو ⋮ ← «تثبيت ZeroPlus».

كيف أفعّل التنبيهات؟

اضغط زر «تنبيهات» أعلى الصفحة أو زر «تفعيل التنبيهات» هنا، ثم اختر سماح / Allow.

لو ظهرت «محظورة»: أندرويد: ⋮ ← الإعدادات ← إشعارات المواقع ← ZeroPlus ← سماح. آيفون: ثبّت التطبيق أولاً، ثم الإعدادات ← الإشعارات ← ZeroPlus ← السماح بالإشعارات.

لا تنسَ: أطفئ «وضع التركيز/عدم الإزعاج» في الهاتف، واسمح للتطبيق بالعمل بالخلفية من إعدادات البطارية.

كيف أبدّل المظهر (فاتح / داكن / تلقائي)؟

تبديل سريع: زر الشمس/القمر أعلى الصفحة يقلب بين الفاتح والداكن فوراً.

الأوضاع الثلاثة: من بطاقة «مظهر التطبيق» هنا أو في الرئيسية: فاتح ثابت، داكن ثابت، أو تلقائي يتبع إعداد نظام جهازك ويتبدّل معه لحظياً (مفيد لو عندك جدولة ليلية في الهاتف).

الاختيار يُحفظ تلقائياً ويبقى كما هو في كل مرة تفتح التطبيق، حتى بعد الإغلاق.

حسابي: إنشاء، دخول، نسيان كلمة المرور

الإنشاء: شاشة الترحيب ← الاسم الأكاديمي + كلمة مرور (4 خانات فأكثر) + اختيار القسم.

الدخول من جهاز آخر: نفس الاسم ونفس كلمة المرور — تُجلب مهامك وجلساتك ونقاطك من السحابة تلقائياً.

تغيير كلمة المرور: صورة الحساب أعلى الصفحة ← «كلمة مرور جديدة» ← حفظ التعديلات.

نسيت كلمة المرور: راسل الدعم عبر تيليجرام مع اسمك الأكاديمي وقسمك لإعادة تعيينها.

المزامنة وحفظ البيانات

النقطة أعلى الصفحة: مزامن | تغييرات بانتظار الرفع | فشل مزامنة | غير متصل.

كل تغيير يُحفظ محلياً أولاً ثم يُرفع تلقائياً عند عودة الإنترنت أو عند فتح التطبيق — لا تفقد شيئاً بوضع الطيران.

حالة السحابة: —

هل يعمل مؤقت التركيز بالخلفية؟

نعم. عند الضغط على «بدء المؤقت» يُسلَّم الوقت للخدمة الخلفية (Service Worker) التي تُطلق إشعار «انتهى الوقت» حتى لو أغلقت الصفحة أو صغّرتها.

عند رجوعك للتطبيق تُحسب الجلسة وتُسجَّل تلقائياً في سجلك حتى لو انتهت وأنت بالخارج.

لأفضل نتيجة: فعّل التنبيهات، واسمح للتطبيق بالعمل بالخلفية، ولا تُغلقه من قائمة التطبيقات المفتوحة قبل انتهاء الجلسة.

الخصوصية وحذف بياناتي

لا نطلب بريداً ولا رقماً — الحساب بالاسم والقسم فقط، وبياناتك مربوطة بجهازك/حسابك.

«مسح السجل» في تبويب التركيز يحذف الجلسات من الجهاز ومن السحابة معاً.

لحذف الحساب نهائياً راسل الدعم وسنحذف صفّك من القاعدة.
